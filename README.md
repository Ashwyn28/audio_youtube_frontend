# AudioTube frontend

The SvelteKit application lives in [`audio-youtube-frontend/`](audio-youtube-frontend/).
See its [README](audio-youtube-frontend/README.md) for setup, configuration and tests.

The production site is https://audio-youtube.orbbits.io. Its native audio/search API
lives in [audio_youtube](https://github.com/Ashwyn28/audio_youtube). Vercel builds use
the Vercel adapter; local and Docker builds use the Node adapter.
